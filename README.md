# Data Analysis with Python - freeCodeCamp Projects

This repository contains the 5 certification projects completed for the **freeCodeCamp Data Analysis with Python** curriculum.

## Projects Included

1. **Mean-Variance-Standard Deviation Calculator** (`mean_var_std/`)
   * Calculations across matrix axes using NumPy.
2. **Demographic Data Analyzer** (`demographic_data/`)
   * Demographic data exploration and querying using Pandas.
3. **Medical Examination Visualizer** (`medical_data/`)
   * Categorical plots and correlation heatmaps using Seaborn and Matplotlib.
4. **Page View Time Series Visualizer** (`time_series/`)
   * Trend analysis, line charts, and box plots on time series data.
5. **Sea Level Predictor** (`sea_level/`)
   * Historical data visualization and linear regression forecasting up to 2050 using SciPy and Matplotlib.
